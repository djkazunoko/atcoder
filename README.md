# atcoder

競技プログラミングの学習記録です。AtCoderを中心に、解いた問題のRubyのコードをまとめています（2025年8月〜）。

## ディレクトリ構成

| ディレクトリ | 内容 |
| --- | --- |
| `ABC/` | AtCoder Beginner Contest の問題（コンテストに参加して解いた問題と、過去問） |
| `ABS/` | [AtCoder Beginners Selection](https://atcoder.jp/contests/abs)（全問） |
| `AOJ/ITP1/` | AOJ [Introduction to Programming I](https://onlinejudge.u-aizu.ac.jp/courses/lesson/2/ITP1/all)（全40問） |
| `tessoku-book/` | 『競技プログラミングの鉄則』の演習問題（章ごと） |
| `others/` | その他のコンテストの問題（コンテストIDごと） |

## 学習の進め方

* コンテストごとにPull Requestを作成し、その回で解いた問題をまとめています。
* 自力で解いた提出と、解説を読んでから解き直した提出を分けてコミットしています。コミットメッセージに結果を記載しているため、試行錯誤の過程を追えるようにしています。
  * `自力AC`：自力で正解
  * `WA` / `TLE` / `RE`：不正解・実行時間超過・実行時エラー
  * `解説AC`：解説を読んで理解したうえで、解き直して正解
* コンテスト後は、解けなかった問題も解説や解説放送をもとに復習しています。
  * `.cpp` ファイルは、解説放送の参考実装（C++）を理解のために写したものです。
